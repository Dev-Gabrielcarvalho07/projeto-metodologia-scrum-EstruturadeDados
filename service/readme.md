# Camada Service

Esta pasta centraliza as **Regras de Negócio** e a implementação dos **Algoritmos**.

- **Algoritmos de Busca:** Busca Sequencial e Binária.
- **Algoritmos de Ordenação:** Bubble Sort e Selection Sort.
- **Estrutura de Dados:** Implementação da Tabela Hash e gerenciamento da lista de produtos.
- **Regra:** As assinaturas dos métodos devem seguir rigorosamente o padrão estabelecido no plano de projeto.
