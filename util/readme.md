# Camada Util

Esta pasta contém as **Funções Auxiliares** e utilitários que dão suporte ao funcionamento do sistema.

- **Leitura de Dados:** Métodos para capturar entradas via console (Scanner).
- **Impressão:** Formatação e exibição de listas e resultados de buscas no console.
- **Apoio:** Métodos genéricos que podem ser reaproveitados por diferentes serviços.
