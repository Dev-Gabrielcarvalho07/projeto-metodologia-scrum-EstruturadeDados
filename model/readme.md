# Camada Model

Esta pasta contém as **Classes de Entidade** que representam a estrutura de dados do sistema.

- **Foco:** Definição de atributos e tipos de dados.
- **Exemplo:** Classe `Produto.java` com `id`, `nome` e `preco`.
- **Regra:** Não deve conter lógica de negócio ou algoritmos, apenas a representação do que o sistema é.
